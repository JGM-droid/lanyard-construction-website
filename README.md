# Lanyard Construction Services Website Prototype Planning

## Purpose
This repository contains planning documentation for a polished, responsive prototype website for Lanyard Construction Services focused on commercial and multifamily renovation work.

This phase is documentation-only. It defines requirements, content needs, workflow, and delivery phases before any framework selection or application code begins.

## Scope Guardrails
- Documentation only.
- No application code in this phase.
- No dependency installation.
- No framework initialization.
- No commits required by this document set.
- Guardian Construction Services website is design inspiration only. Do not copy branding, wording, layouts verbatim, or proprietary assets.
- Any unverified business claim, statistic, testimonial, certification, project detail, or image must be labeled as Placeholder or Open Question until client confirmation.

## Status Labels (Used Across All Docs)
- Confirmed: Approved requirement or decision captured in this planning cycle.
- Assumed: Working assumption for prototype planning; must be validated by client.
- Placeholder: Temporary copy, media, or detail used only for layout/prototype; not verified fact.
- Open Question: Unresolved item requiring client decision or evidence.

## Initial Prototype Page Set
1. Home
2. Services Overview
3. Exterior Renovations
4. Projects
5. About
6. Contact / Request a Consultation

## Contact Form Prototype Rule
The contact form is a non-submitting prototype in this phase. It should simulate interaction only and must not send data.

## Working Principles for Future Implementation
- Position Lanyard as an established commercial and multifamily contractor as a project goal, not a verified factual claim unless client evidence is provided.
- Keep placeholder markers visible in early demos to prevent accidental representation of draft facts as final facts.
- Enforce responsive design, accessibility, performance, basic SEO, and mobile navigation requirements from the first implementation pass.
